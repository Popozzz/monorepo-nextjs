# next-intl Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add multi-language support (en + zh-CN) to the monorepo's Next.js app using next-intl, with shared i18n infrastructure in a new `@repo/i18n` package.

**Architecture:** A shared `packages/i18n` package owns routing config, navigation helpers, the request config, and message files. The Next.js app (`apps/`) keeps only Next-specific wiring: `next.config.ts` plugin, `proxy.ts` (Next 16's renamed `middleware.ts`), a one-line request re-export, and pages migrated under `app/[locale]/`.

**Tech Stack:** Next.js 16.2.12 (App Router), React 19.2.3, next-intl ^4.13.4, pnpm 10.15.1, TypeScript.

## Global Constraints

- Locales are exactly `['en', 'zh-CN']`; `defaultLocale` is `'en'`; `localePrefix` is `'always'` (URLs look like `/en/home`, `/zh-CN/home`).
- All user-visible strings on migrated pages come from messages — no hardcoded text on those pages.
- No test framework exists in the repo. Verification is: package type-check via `tsc`, `pnpm --filter apps build`, `pnpm --filter apps lint`, and manual smoke checks.
- Next.js 16 conventions: routing middleware file is `proxy.ts` (not `middleware.ts`); route `params` are `Promise<{...}>` and must be awaited.
- Do not add comments to code unless a step explicitly shows them.
- Commit after every task. Each commit message follows the repo style (lowercase `type(scope): description`).

## File Structure

New `packages/i18n` package (no build step, exports TS source directly — mirrors `@repo/ui`):

- `packages/i18n/package.json` — name `@repo/i18n`, exports map for `.`, `./routing`, `./navigation`, `./request`
- `packages/i18n/tsconfig.json` — extends `../../tsconfig.base.json`, standalone type-check options

- `packages/i18n/messages/en.json`, `packages/i18n/messages/zh-CN.json` — message namespaces: `Metadata`, `Home`, `HomePage`, `Switcher`

App files touched:

- `apps/package.json` — add `@repo/i18n` + `next-intl` dependencies

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested)

    messages: (await import(`../messages/${locale}.json`)).default,
  };
});

```tsx
import type { Metadata } from "next";
import { Geist, Geist_Mono } from "next/font/google";
import { hasLocale, NextIntlClientProvider } from "next-intl";
import {
  getMessages,
  getTranslations,
  setRequestLocale,
} from "next-intl/server";
import { notFound } from "next/navigation";
import { routing } from "@repo/i18n/routing";
import "../globals.css";

const geistSans = Geist({
  variable: "--font-geist-sans",
  subsets: ["latin"],
});

const geistMono = Geist_Mono({
  variable: "--font-geist-mono",
  subsets: ["latin"],
});

export function generateStaticParams() {
  return routing.locales.map((locale) => ({ locale }));
}

export async function generateMetadata({
  params,
}: {
  params: Promise<{ locale: string }>;
}): Promise<Metadata> {
  const { locale } = await params;
  const t = await getTranslations({ locale, namespace: "Metadata" });
  return {
    title: t("title"),
    description: t("description"),
  };
}

export default async function LocaleLayout({
  children,
  params,
}: Readonly<{
  children: React.ReactNode;
  params: Promise<{ locale: string }>;
}>) {
  const { locale } = await params;
  if (!hasLocale(routing.locales, locale)) {
    notFound();
  }
  setRequestLocale(locale);

  const messages = await getMessages();

  return (
    <html lang={locale}>
      <body
        className={`${geistSans.variable} ${geistMono.variable} antialiased`}
      >
        <NextIntlClientProvider messages={messages}>
          {children}
        </NextIntlClientProvider>
      </body>
    </html>
  );
}
```

- [ ] **Step 1: Create `apps/app/components/LocaleSwitcher.tsx`**

```tsx
"use client"

import { useTransition, type ChangeEvent } from "react"
import { useLocale, useTranslations } from "next-intl"
import { usePathname, useRouter } from "@repo/i18n/navigation"
import { routing } from "@repo/i18n/routing"

export default function LocaleSwitcher() {
  const locale = useLocale()
  const t = useTranslations("Switcher")
  const router = useRouter()
  const pathname = usePathname()
  const [isPending, startTransition] = useTransition()

  function onSelectChange(event: ChangeEvent<HTMLSelectElement>) {
    const nextLocale = event.target.value
    startTransition(() => {
      router.replace(pathname, { locale: nextLocale })
    })
  }

  return (
    <label className="fixed top-4 right-4 z-50 flex items-center gap-2 text-sm text-zinc-700 dark:text-zinc-300">
      <span>{t("label")}</span>
      <select
        defaultValue={locale}
        onChange={onSelectChange}
        disabled={isPending}
        className="rounded-md border border-zinc-300 bg-white px-2 py-1 dark:border-zinc-700 dark:bg-zinc-900"
      >
        {routing.locales.map((cur) => (
          <option key={cur} value={cur}>
            {cur}
          </option>
        ))}
      </select>
    </label>
  )
}
```
